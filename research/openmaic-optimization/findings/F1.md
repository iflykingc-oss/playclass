## Dead ends
- Google / DuckDuckGo / Bing 等通用搜索引擎在本环境 webfetch 时 Transport error 或被取消，未能抓到第三方博客/论坛/媒体评测（如 InfoQ、少数派、Reddit、V2EX）的独立用户反馈；外部社区声量未验证。
- Discord（discord.gg/p8Pf2r3SaG）为邀请制聊天，无可索引公开历史；飞书群仅二维码（community/feishu.md），无导出讨论记录。
- GitHub Discussions 第 1 页已覆盖 Ideas/Q&A/Show-and-tell 主线，但部分 Q&A（#532 MiniMax TTS、#595 生成失败、#748 TTS 音色、#951 讲师应答）均 Unanswered，无法从回复中量化影响面。
- playclass 作为二次开发产品，仓库内未见独立的用户反馈/工单系统导出；上述结论主要基于上游 THU-MAIC/OpenMAIC 主仓，playclass 平台层（账户/计费/机构）反馈证据偏弱。
- 未能逐条打开全部 150 个 open issue 正文；聚类基于 issues 列表标题 + API dump（最近 ~50 条）+ 重点 issue/discussion 全文。
